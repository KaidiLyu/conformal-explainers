# 论文阅读与复现决策

来源：Alkhatib & Lowry, [arXiv:2509.21209v1](https://arxiv.org/html/2509.21209v1)，重点核对第 3–4 节、附录 B/H/I。以下内容为本项目对论文的理解和工程决策，不是作者认可的勘误。

## 方法对应

1. 用原图预测类别作为解释目标；所有解释器使用同一个模型的类别概率。
2. 对校准图片尝试多个归因阈值，保留超过阈值的像素或相关超像素。
3. 记录能保持原图预测的最大候选阈值，对应正文公式 (3)/(4)。
4. 用校准集分数计算共享阈值；测试阶段只使用该固定阈值，不根据测试预测修补掩码。
5. fidelity 衡量掩码前后预测是否一致；accuracy 衡量是否预测正确，两者分别报告。

## 明确记录的差异

| 项目 | 论文或附录 | 基础实现 |
|---|---|---|
| 校准方式 | 四种 | 按提案实现三种；Summed Values 不在本阶段范围 |
| 数据集 | 六个 | 正式目标只有 Imagenette；Animals-10 为可选扩展 |
| 数据划分 | 表 5 提供数量 | 匹配数量，seed=42 独立分层划分 |
| 输入归一化 | 文中写训练集均值/标准差 | 使用 ImageNet 预训练统计，已明确为复现差异 |
| 输入尺寸/增强 | 细节不完整 | 224×224 缩放，分类器训练时随机水平翻转 |
| 掩码替代值 | baseline removal | 归一化空间的零，即显示空间的均值色 |
| rho | 正文称比例；公式/附录使用数量，默认 100 | 同时支持 fraction/count；默认 fraction=0.5，不声称等同附录 |
| SLIC | 50 区域、compactness=10、sigma=1；附录直接用输入 | 同参数，但在还原 RGB 图像上分割，避免将归一化值当颜色 |
| 阈值候选 | 分位数；附录 1–99 百分位 | 默认 0–100 百分位，去重并增加全图回退 |
| 校准分位数 | 正文计数加一；附录 NumPy percentile | 默认逐字实现正文不等式；不使用插值 percentile |
| 通道聚合 | 未充分规定 | 梯度方法求和 RGB；Saliency 先取绝对值，其余保留符号 |
| SHAP 特征粒度 | 细节不充分 | KernelSHAP/FastSHAP 统一 7×7 规则网格，其余为像素梯度 |
| FastSHAP 网络 | 未提供完整可直接运行配置 | 小型卷积网络＋作者训练目标，需正式训练与验证 |

正文比例模式可通过 `rho_mode: fraction, rho: 0.5` 使用。附录数量模式对应 `rho_mode: count, rho: 100`。小于 100 像素的区域在数量模式中可能永远不被选中；本实现通过显式全图回退避免无有效候选。这个回退必须记录，不能隐藏。

## 数值与理论边界

- 附录把失败阈值乘以零，再把所有零改为负无穷，会丢失有效的零阈值。本实现直接用布尔条件选择成功阈值，也支持负归因值。
- 常数图的标准差为零，Scaled Values 返回全零归因而不是 NaN。
- 归因并列值使用 `>=`；按离散候选处理并列分数。
- 默认 `paper` 分位数严格对应正文 `(count(sigma_i >= sigma)+1)/(n+1) >= confidence`。`conservative` 使用下侧秩 `floor((n+1)*alpha)`，秩为零时保留整图。两种规则不能混称完全相同。
- 我们的分析：掩码区域增大不保证分类结果单调保持一致。因此“某个最大阈值能成功”并不能自动推出所有更小阈值都成功。代码扫描全部候选，不做二分搜索；即使换成保守分位数，也不据此宣称对任意模型具有 fidelity 保证。正式报告应给出实测 fidelity、样本量和区间。
- 预训练权重见过 ImageNet，Imagenette 又是其子集。这是预训练设定，需要与从头训练区分，不能把它描述成完全未见过样本的分类泛化评估。

## 尚待研究确认

选择的网络架构、归因输出尺度、rho、超像素参数和网格大小都会影响解释面积。应在开发阶段用训练/验证数据决定规则，冻结后再开展校准和最终测试。完整训练、论文数字对照及失败分析尚未进行。
