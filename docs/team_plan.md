详细阶段安排、论文对照目标及 Cloud Bursting 预算见 [复现执行计划](reproduction_plan.md)（2026-10-29 更新）。

四人分工按“一个人负责 Saliency＋Input × Gradient，另三人各负责一种 SHAP”组织；具体姓名由组内最终确认。

| 责任 | 主要文件 | 下一步 |
|---|---|---|
| Saliency / Input × Gradient | explainers.py、calibration.py | 核对通道/符号约定，完成梯度方法正式结果 |

| GradientSHAP | explainers.py、app.py | 检查基线和噪声设置，完成可视化和 Demo 整合 |

共同责任：固定分类器和数据划分、审查校准定义、比较论文、失败分析、报告和展示。

## 阶段验收

1. **基础代码**：无需真实数据即可通过单元测试和合成流程检查；当前版本处于此阶段。
2. **模型就绪**：真实数据划分已固定，分类器与 FastSHAP 正式训练完毕，验证记录可审查。
3. **实验就绪**：所有开发参数已冻结，校准和测试集隔离，正式结果包含样本量和文件指纹。
4. **分析就绪**：至少完成 fidelity/面积/耗时对照、置信度曲线、成功与失败案例及差异解释。
5. **提交就绪**：仓库能按文档重现，Demo 可展示，报告与 slides 完整，组员能讲解代码及贡献。

进度按以上成果判断，不以代码行数、测试通过数或合成数据实验数量代替研究完成度。

## 2026-10-29 开发进展

已补齐结果分析工具：`conformal-cv report --results <实验目录>` 可输出曲线、逐配置统计、去重耗时和失败案例清单。工具已在合成结果上验证；阶段 4 的正式分析仍依赖阶段 2、3 的真实训练和实验。
